معرض أعمال محمد المنتصر — نسخة أولية قابلة للنشر مجاناً

محتويات الحزمة:
- index.html: صفحة الموقع.
- style.css: التصميم والألوان والتجاوب مع الجوال.
- app.js: وظائف البحث والتصفية والتبديل بين العربية والإنجليزية وفتح تفاصيل المشاريع.
- projects.js: بيانات المشاريع والنصوص والصور المرتبطة بها.
- assets/: الصور المستخرجة من ملف PowerPoint.

المحتوى الحالي:
- 36 مشروع تصميم معماري.
- مشروع رفع معماري As-Built.
- مشروع ترميم واجهة.
- مشروع تنفيذي (فندق المثابة).

مهم قبل النشر:
1) راجع البيانات، خصوصاً المشاريع 30–33؛ عنوانها في العرض Residential Building بينما خانة Project Type تذكر Villa. أبقينا النصين كما وردا ولم نصحح التعارض من تلقاء أنفسنا.
2) بعض المشاريع في ملف PowerPoint لا تحتوي على وصف تفصيلي، لذلك استخدمنا وصفاً مختصراً مستنداً إلى المعلومات الظاهرة فقط.
3) راجع ترجمة أسماء المواقع، وأرسل أي تصحيحات ترغب بها.

طريقة التعديل:
- لتعديل وصف مشروع أو مساحة أو موقع، افتح projects.js وعدّل الحقول المقابلة للمشروع.
- لإضافة مشروع تصميم، أضف عنصراً جديداً إلى مصفوفة design داخل projects.js مع الحقول نفسها الموجودة في المشاريع السابقة.
- أضف الصور الجديدة إلى مجلد assets، ثم اكتب أسماء ملفاتها في مصفوفة images للمشروع.
- أقسام الرفع والترميم داخل asbuilt، والتنفيذ داخل contracting.

النشر المجاني المقترح:
يمكن نشر هذه الحزمة كصفحة ثابتة عبر GitHub Pages مجاناً. لا تحتاج شراء نطاق؛ سيعطيك GitHub رابطاً مجانياً تابعاً له. هذا الموقع ليس منشوراً على الإنترنت بعد، وهذه الحزمة هي ملفات الموقع الجاهزة للمعاينة والنشر. نشره يتطلب تسجيل الدخول إلى حساب GitHub ورفع الملفات وتفعيل Pages.

لا تضع كلمات مرور أو بيانات خاصة داخل ملفات الموقع. بيانات الاتصال الظاهرة مأخوذة من ملف البروفايل الذي أرسلته.
